Suggested script

  1. Phone: open the patient page and read the wait. Then open the demo phone in another tab, enter a phone number such as (555) 010-4477, and text WAIT.
  2. Phone: tap Join the line with the same number. The 4-digit code arrives on the demo phone; enter it to get the line ID and code.
  3. Laptop: set the clock to 30× and watch the front desk. When the confirmation text arrives, reply Y on the demo phone.
  4. Laptop: scan the phone's code (or type the line ID), tap Mark arrived, then Call to room when the green banner appears.
  5. Privacy check: on the laptop, open the patient page in a private window and try to join with the phone's number. The page asks for a code and reveals nothing.
